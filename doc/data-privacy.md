## 1. 隐私设计原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **零泄露承诺** | P0级数据（持仓、账户、策略参数）绝不离开用户本机 |
| **最小化上传** | 只有经过脱敏的P1/P2级数据才可上传云端 |
| **本地优先推理** | 含敏感数据的消息强制本地处理 |
| **可审计** | 每次云端调用都有完整日志，用户可审查 |
| **可逆脱敏** | 脱敏数据可在本地还原，确保回复上下文完整 |

### 1.2 隐私分级定义

```
┌──────────────────────────────────────────────────────────────┐
│                     隐私分级体系                               │
│                                                               │
│  🔴 P0 - 绝密 (Strictly Local)                               │
│  │  绝不外传，仅限本地处理                                     │
│  │  ├── 持仓数据: "我持有500手螺纹钢"                         │
│  │  ├── 账户信息: "账户余额50万"                              │
│  │  ├── 策略参数: "我的止损设在3800"                          │
│  │  ├── 交易记录: "昨天在3850入了螺纹钢"                     │
│  │  └── 资金相关: "仓位比例1/3"                               │
│  │                                                             │
│  🟡 P1 - 内部 (Sanitize & Send)                              │
│  │  脱敏后可上传云端，回复在本地还原                           │
│  │  ├── 策略框架: "我用突破回踩策略" (去除具体参数)           │
│  │  ├── 市场分析: "螺纹钢趋势向上" (去除持仓信息)            │
│  │  ├── 交易思路: "我不喜欢追涨" (风格偏好)                   │
│  │  └── 教学内容: "我的入场条件是..." (去除具体标的和价格)    │
│  │                                                             │
│  🟢 P2 - 公开 (Free to Send)                                 │
│     可直接上传云端                                             │
│     ├── 通用交易知识: "什么是均线金叉"                        │
│     ├── 书籍内容: "《以交易为生》中说..."                     │
│     ├── 公开市场数据: "今日螺纹钢收盘价3850"                 │
│     └── 理论讨论: "趋势跟踪和均值回归的区别"                 │
└──────────────────────────────────────────────────────────────┘
```

## 2. 隐私检测

### 2.1 三重检测机制

```
用户消息
    │
    ▼
┌──────────────────────────────────────────────────────┐
│              三重隐私检测管道                          │
│                                                       │
│  Layer 1: 关键词正则匹配 (快速, <10ms)                │
│  ├── P0关键词: ["持仓", "账户", "余额", "仓位",      │
│  │              "手数", "盈亏", "止损", "止盈"]       │
│  ├── P1关键词: ["策略", "我的", "我一般", "我通常"]   │
│  └── 规则: 命中P0关键词 → 直接标记P0                 │
│                                                       │
│  Layer 2: NER实体识别 (中等, ~100ms)                  │
│  ├── 识别: 具体品种名 + 数量/价格 组合                │
│  │  "螺纹钢500手" → [品种:螺纹钢, 数量:500手]        │
│  ├── 识别: 价格 + 方向 组合                           │
│  │  "在3850入场做多" → [价格:3850, 方向:做多]        │
│  └── 规则: 实体组合 → 标记P0                         │
│                                                       │
│  Layer 3: 本地小模型语义理解 (较慢, ~300ms)           │
│  ├── 判断: 消息是否隐含持仓/账户/策略参数信息        │
│  ├── 示例: "我那单还在" → 隐含持仓信息 → P0          │
│  └── 规则: 模型判断含敏感 → 标记P0/P1               │
│                                                       │
│  综合决策:                                             │
│  ├── 任一层标记P0 → 最终P0                           │
│  ├── 任一层标记P1且无P0 → 最终P1                     │
│  └── 全部标记P2 → 最终P2                             │
└──────────────────────────────────────────────────────┘
```

## 3. 数据脱敏与还原

### 3.1 脱敏管道

```
原始消息 (P1)
    │
    ▼
┌──────────────────────────────────────────────────────┐
│                  脱敏处理管道                          │
│                                                       │
│  Step 1: 实体识别与替换                               │
│  ├── 品种名 → [COMMODITY]                            │
│  │  "螺纹钢" → "[COMMODITY_1]"                      │
│  ├── 数量 → [QUANTITY]                               │
│  │  "500手" → "[QUANTITY_1]"                        │
│  ├── 价格 → [PRICE]                                  │
│  │  "3850" → "[PRICE_1]"                            │
│  ├── 止损/止盈位 → [STOP_LOSS]/[TAKE_PROFIT]        │
│  │  "止损3780" → "止损[STOP_LOSS_1]"               │
│  └── 具体日期 → [DATE]                               │
│     "昨天" → "[DATE_1]"                             │
│                                                       │
│  Step 2: 上下文保留                                   │
│  ├── 保留交易方向 (多/空)                             │
│  ├── 保留策略类型 (突破/回踩/趋势)                    │
│  └── 保留风格偏好 (保守/激进)                         │
│                                                       │
│  Step 3: 语义完整性检查                               │
│  ├── 脱敏后消息是否仍可理解？                         │
│  └── 是否遗漏了敏感信息？                             │
└──────────────────────────────────────────────────────┘
```

### 3.2 脱敏映射表

每次脱敏生成一个映射表，本地保存，用于还原：

```json

  "original_message": "我持有500手螺纹钢，成本3800，止损3780，现在该不该加仓？",
  "sanitized_message": "我持有[QUANTITY_1][COMMODITY_1]，成本[PRICE_1]，止损[STOP_LOSS_1]，现在该不该加仓？",
  "mappings": {
    "[QUANTITY_1]": "500手",
    "[COMMODITY_1]": "螺纹钢",
    "[PRICE_1]": "3800",
    "[STOP_LOSS_1]": "3780"
  },
  "context_preserved": {
    "direction": "long",
    "strategy_type": "breakout",
    "risk_preference": "conservative"
  }
}
```

### 3.3 还原管道

```
云端回复
    │
    ▼
┌──────────────────────────────────────────────────────┐
│                  还原处理管道                          │
│                                                       │
│  Step 1: 占位符替换                                   │
│  ├── "[COMMODITY_1]" → "螺纹钢"                      │
│  ├── "[PRICE_1]" → "3800"                            │
│  └── 使用本地保存的映射表                             │
│                                                       │
│  Step 2: 计算补充                                     │
│  ├── 云端回复: "建议止损设在成本下方1%"               │
│  ├── 本地计算: 3800 * (1-0.01) = 3762               │
│  └── 还原后: "建议止损设在3762"                       │
│                                                       │
│  Step 3: 上下文增强                                   │
│  ├── 补充具体品种信息                                 │
│  ├── 补充当前持仓信息                                 │
│  └── 生成最终回复                                     │
└──────────────────────────────────────────────────────┘
```

## 4. 数据生命周期

### 4.1 数据分类与存储策略

```
┌──────────────────────────────────────────────────────────────┐
│                    数据分类与存储                              │
│                                                               │
│  📁 本地存储 (永不外传)                                       │
│  ├── 持仓数据 (实时)                                         │
│  ├── 交易日志 (永久)                                         │
│  ├── 策略卡片完整版 (含参数) (永久)                          │
│  ├── 脱敏映射表 (会话级, 1小时后删除)                        │
│  ├── 对话记录原始版 (永久, 用于蒸馏)                         │
│  └── LoRA权重文件 (永久)                                     │
│                                                               │
│  📁 本地缓存 (定期清理)                                       │
│  ├── 语义缓存 (7天TTL)                                       │
│  ├── 上下文压缩缓存 (会话级)                                 │
│  └── 行情数据缓存 (1天TTL)                                   │
│                                                               │
│  📁 云端 (仅脱敏数据)                                         │
│  └── API请求/响应 (供应商短期日志, 不可控)                   │
│      → 确保请求中不含P0数据                                  │
│                                                               │
│  🗑️ 不存储                                                    │
│  ├── 云端对话历史 (不依赖云端记忆)                           │
│  └── 第三方服务数据 (不使用需上传数据的服务)                 │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 数据保留策略

| 数据类型 | 保留期限 | 清理策略 |
|---------|---------|---------|
| 对话记录 | 永久 | 用户可手动删除 |
| 策略卡片 | 永久 | 用户可手动删除 |
| 交易日志 | 永久 | 用户可手动删除 |
| 蒸馏训练样本 | 永久 | 模型训练完成后仍保留，支持重训 |
| 脱敏映射表 | 1小时 | 定时清理 |
| 语义缓存 | 7天 | LRU + TTL |
| 行情数据 | 1天 | 每日覆盖 |
| API调用日志 | 90天 | 自动清理 |
| LoRA权重 | 永久 | 保留最近3个版本 |
| 评估报告 | 永久 | 可导出后删除 |

### 4.3 数据加密

```python
# src/common/crypto.py

from cryptography.fernet import Fernet
import base64

class DataEncryptor:
    """本地敏感数据加密"""
    
    def __init__(self, key: bytes | None = None):
        if key is None:
            # 从环境变量或配置文件读取
            key = self._load_or_generate_key()
        self.cipher = Fernet(key)
    
    def encrypt(self, data: str) -> str:
        """加密数据"""
        return self.cipher.encrypt(data.encode()).decode()
    
    def decrypt(self, encrypted: str) -> str:
        """解密数据"""
        return self.cipher.decrypt(encrypted.encode()).decode()
    
    def _load_or_generate_key(self) -> bytes:
        """加载或生成加密密钥"""
        key_path = Path("./data/.encryption_key")
        if key_path.exists():
            return key_path.read_bytes()
        key = Fernet.generate_key()
        key_path.write_bytes(key)
        key_path.chmod(0o600)  # 仅所有者可读写
        return key

# 加密存储的字段
ENCRYPTED_FIELDS = [
    "position_details",    # 持仓详情
    "account_balance",     # 账户余额
    "trade_records",       # 交易记录
    "strategy_params",     # 策略参数
]
```

## 5. 云端调用安全

### 5.1 调用前检查清单

```
每次云端API调用前，自动执行:

□ 隐私检测: 确认消息不包含P0级数据
□ 脱敏完成: P1级数据已替换为占位符
□ 上下文压缩: 历史对话已压缩，去除敏感片段
□ 最小化原则: 仅发送必要的最少信息
□ 调用记录: 已记录调用目的和数据摘要
```

## 6. 审计与合规

### 6.1 审计日志

```sql
-- 云端调用审计表
CREATE TABLE cloud_api_audit (
    id TEXT PRIMARY KEY,
    timestamp DATETIME NOT NULL,
    provider TEXT NOT NULL,        -- deepseek / openai
    model TEXT NOT NULL,
    purpose TEXT NOT NULL,         -- 路由决策 / 深度推理 / 数据精炼
    privacy_level TEXT NOT NULL,   -- P1 / P2
    sanitized BOOLEAN DEFAULT FALSE,
    input_tokens INTEGER,
    output_tokens INTEGER,
    cost_cny REAL,                 -- 费用(元)
    original_message_hash TEXT,    -- 原始消息哈希(不可逆)
    success BOOLEAN,
    error_message TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 6.2 隐私合规检查

```
每日自动执行隐私合规检查:

1. 审计日志审查
   ├── 是否有P0级数据被发送到云端？
   │   → 如果有，立即告警 + 回溯原因
   └── 脱敏映射表是否按时清理？

2. 缓存清理
   ├── 过期的语义缓存是否已清理？
   └── 过期的脱敏映射表是否已清理？

3. 加密验证
   └── 本地敏感数据是否都已加密存储？

4. 生成每日隐私报告
   └── 推送到飞书
```

## 8. 蒸馏数据隐私

### 8.1 蒸馏数据脱敏

训练数据在进入蒸馏流水线前，也需要脱敏处理：

```
原始对话 (可能含P0数据)
    │
    ▼
蒸馏数据脱敏
    │
    ├── 具体品种 → 通用描述
    │  "螺纹钢突破" → "某品种突破"
    │
    ├── 具体价格 → 相对描述
    │  "突破3850" → "突破关键位"
    │
    ├── 具体数量 → 比例描述
    │  "500手" → "计划仓位"
    │
    └── 具体日期 → 去除
       "昨天" → "近期"
    
    ▼
脱敏后训练样本 (可安全用于训练)
```

### 8.2 训练后隐私验证

```
模型训练完成
    │
    ▼
```
